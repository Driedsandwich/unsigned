Interface preview · Not connected
For AI agents
These are the proposed tools. This prototype only documents them; it exposes no working agent endpoint.

              

                
get_themes
Returns aggregated themes and respondent bands only. Themes with fewer than 3 distinct people are excluded.

                
draft_check_in_question
Creates a question draft from visible themes. Prefers on-device AI; uses cloud AI only when on-device AI is unavailable.

                
schedule_check_in
Places a proposed check-in in draft status only. A human must confirm before it can be scheduled or published.

              

              
Never exposed through these tools
  • Raw responses
  • Themes with fewer than 3 people, including their text or counts
  • Individual responses, even approved rewrites

              
The respondent’s simulated payload is shown only in their own receipt. Admin sees aggregate themes. No tool above can be invoked from this page.
