    For AI agents

    Connect the local Node MCP server described in README. These tools never perform AI inference.

    get_themes
    Returns aggregated themes and respondent bands only. Themes supported by fewer than 3 distinct anonymous sign-ins per question are excluded.
    draft_check_in_question
    Returns the administrator’s request as an editable draft. No inference and no publishing.
    schedule_check_in
    Places a proposed check-in in draft status only. A human must confirm before it can be scheduled or published.

    Never exposed through these tools

    • Raw responses
    • Themes with fewer than 3 people, including their text or counts
    • Individual responses, even approved rewrites

    The local MCP server returns only aggregate themes and bands. Requests to schedule are saved as drafts requiring human confirmation.
